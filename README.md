# AI Mate — Backend 🚀

> **Spring Boot Backend Service for AI Mate**

Backend microservice handling student notes ingestion, OCR pipelines, AI model integration, and user revision schedules.

## 🛠️ Tech Stack
- **Framework**: Java 17 + Spring Boot 4.x
- **Data Persistence**: Spring Data JPA + MySQL
- **Security**: Spring Security
- **Build Tool**: Maven

## 🚀 Getting Started

1. Configure your MySQL database settings in `src/main/resources/application.properties`.
2. Build and run the service:
   ```bash
   ./mvnw spring-boot:run
   ```
